01

Get your Alchemy app key.

Use your default app, or create one for Kira.

  1. Open the Alchemy dashboard ↗.
  2. Use an existing app or choose Apps → Create new app.
  3. Enable your networks and the Node API and Portfolio API services.
  4. Copy the app's API key.

You need one app key. You do not need a separate URL for every network.

Official walkthrough ↗
02

Connect privately.

Run this on the computer where Kira is installed.

kira connect alchemy

Paste the app key at the hidden terminal prompt and press Enter. Kira saves it in a private local file.

Keep your key private.Enter it in the terminal only. No browser form, chat or wallet seed phrase is needed.
Use a different workspace
kira --data-dir /path/to/workspace connect alchemy
Use an existing environment file
kira config import-env --file /path/to/alchemy.env

The file contains ALCHEMY_API_KEY=YOUR_KEY. Keep the real value in that file. For a different variable name, add --key-env NAME.

Check the workspace, enabled networks, API services and usage limits in Alchemy. Then retry the connection or refresh holdings. Finding a local key does not confirm that every network is available.
