GET STARTED

Your wallets.
One data connection.

Alchemy is the service Kira uses to find your tokens across networks. Connect your own app once. Kira then reads balances, prices and artwork on your computer.

You do not connect a spending wallet to Alchemy. Your seed phrase and wallet keys are never needed.

1. Get your app key2. Connect locally3. Add your wallet
01

Get your Alchemy app key.

Open the Alchemy dashboard ↗. A new account may already have a default app. Use it, or choose Apps → Create new app.

Enable the networks you use and check that your app can access Node API and Portfolio API. Copy the app's API key from its details page. Kira needs one key, so you do not need to copy each network URL.

Review your Alchemy account's API access and usage limits. Kira's lookups consume your provider allowance.

02

Connect it in your terminal.

Run this command on the computer where Kira is installed:

kira connect alchemy

Paste your app key at the hidden prompt and press Enter. The key will not appear while you type. Kira stores it in a private local file and saves the connection for you.

Do not paste the key into a chat, a browser form or a message. Never enter your wallet's seed phrase.
Using a separate Kira workspace?

Include its directory before the command:

kira --data-dir /path/to/workspace connect alchemy
Already have a private environment file?
kira config import-env --file /path/to/alchemy.env

The file contains ALCHEMY_API_KEY=YOUR_KEY. Keep the real value in that file. For a different variable name, add --key-env NAME.

03

Come back and add your wallet.

In Kira, choose Check connection, then add your public EVM address. Already tracking a wallet? Choose Refresh holdings.

The lookup checks every configured network and all discovered token candidates. There is no 128-token cap. Unsupported sources, unavailable networks and missing artwork or prices remain visible as unknown.

Sell-route analysis is optional. It estimates a sale or redemption for saved holdings. You do not need it to see your tokens, prices or logos.

Return to Kira ↗

If the connection does not work

Check that you ran the command in the right workspace. If a lookup fails, review your app's enabled networks, API access and usage in Alchemy, then retry holdings. A local key being found does not prove every network is available.
