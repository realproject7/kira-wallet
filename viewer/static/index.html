Custom RPC & token coverage

New to Alchemy? Follow these steps
  1. Create your app. Sign in to the Alchemy dashboard. Use the default app, or open Team Overview → Apps → Create new app.
  2. Choose your networks and services. Enable the mainnets you use and check that Node API and Portfolio API access are available for your app. Review your plan and usage limits.
  3. Keep the API key on this computer. Run mkdir -p ~/.config/kira and touch ~/.config/kira/alchemy.env. Open that file in a local text editor and add the app API key, for example ~/.config/kira/alchemy.env containing ALCHEMY_API_KEY=YOUR_KEY. Replace YOUR_KEY in your local editor. Do not paste the key or a credentialed RPC URL into Kira chat or this page.
  4. Connect in your terminal. Run chmod 600 ~/.config/kira/alchemy.env, then kira config import-env --file ~/.config/kira/alchemy.env. Kira uses the file reference for RPC backup and token discovery.
  5. Check and refresh. Use the button below to check the local key, then save your connection. Refresh holdings for an existing wallet. Coverage is confirmed by research, not by finding a key.
