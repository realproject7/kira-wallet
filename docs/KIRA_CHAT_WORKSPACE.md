# Kira conversation workspace

The right chat dock now stays in the same place across portfolio routes. Its
compact header contains history, new chat and expand controls. The conversation
uses the available height and scrolls independently behind a floating bottom
input. Expanding uses a short transform animation and an isolated focus region.
Mobile switches to a full-height chat view. Motion respects reduced-motion
preferences and pauses when the document is hidden.

Kira appears inside working messages and above answers rather than in a large
header. The input halo becomes brighter and faster during chat or wallet
research. The agent voice is concise and composed without changing evidence,
unknown-value or signing constraints. Model output remains escaped and bounded.

The history dialog lists previous sessions and lets users read or continue them.
Memory-only history lasts for the process lifetime. Opt-in local history survives
restarts. Continuation requires exactly the same provider, model and wallet
permissions. A guarded one-use local upgrade receipt can preserve the current
volatile conversation without changing the user's retention preference.

Wallet research stages also appear in the chat tray. Sidebar wallets show an
analysis indicator. A new wallet with no completed snapshot opens Activity
while its first job runs. Existing holdings remain accessible during refresh.
Create wallet is now a direct sidebar action into the encrypted OWS form.
Actual creation still requires the operator's passphrase.

Every select uses a Kira listbox with keyboard navigation, typeahead, selected
states and aligned icons. Portfolio view filters reset after navigation; model
configuration does not. Ordinary polling preserves the current view filters.

## Showcase

The bulky examples section is removed. The hero contains a 42-second looping
video of three reconstructed conversations: coverage gaps, Blast exposure and
forgotten LP positions. No operator addresses or balances were used. APE,
SIGNET, ETH and USDC artwork accompanies illustrative token rows. CASHCAT,
USDB and BLAST monograms are clearly illustrative artwork. The page labels the
conversations as reconstructed. LP discovery is a concept scenario; the current
research engine covers direct holdings. Blast retirement is not asserted.

The video is generated by `scripts/render-showcase.py`. It uses no portfolio
input. Playback can be paused and stops offscreen or in a hidden tab.
Reduced-motion users see the poster until they explicitly play. A text transcript
covers all three scenarios. The public site's controller is self-hosted; the
CSP still blocks external scripts, requests and forms.
