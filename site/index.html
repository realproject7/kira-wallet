macOS · Node.js 22+ · Python 3.11+

Install the app, then open local setup. Connect an installed, signed-in Codex or Claude Code CLI, or close setup and add a wallet first.

Setup guide ↗kira-wallet 0.1.0 on npm ↗
Install from npm
npm install -g kira-wallet
kira setup

The app opens at 127.0.0.1 on your computer.
