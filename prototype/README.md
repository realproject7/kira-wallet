# Kira companion concept studio

An isolated static prototype with synthetic data and explicitly simulated job
states. It has no wallet access, provider calls or connected model chat.
The production viewer remains at its existing port and data directory.

```sh
python3 -m http.server 8792 --bind 127.0.0.1 --directory prototype
```

Open http://127.0.0.1:8792. Inspect Home, a wallet, a network, an exact token
identity, the simulated research journey and the character comparison.
All/5/10 filters and search affect visible positions, not summary totals.
On narrow screens, Kira's notes become a separate navigation destination.

The operator approved the adult webtoon character direction. The Chic
Researcher base portrait is also used in the live viewer. Character selection affects the demo only. The older original
concepts are retained. Art provenance and prompt records are in
`docs/character/generation.json` and the identity review.
